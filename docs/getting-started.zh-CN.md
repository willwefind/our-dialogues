## 先读这一段，能省你很多时间

**这个仓库里没有「App」，不用安装任何软件。** Our Dialogues 是一个网页——
打开就能用。你在仓库里看到的一堆代码文件，就是这个网页本身的零件，
**不需要看懂它们**。

**你唯一需要自己准备的，是「导出的聊天记录」**（第一步教）。
阅读器只是替你读它，不导出、不上传、不注册、不要账号。

| 你的情况 | 走哪条路 |
|---|---|
| 想先看看这是个什么东西 | [在线版](https://willwefind.github.io/our-dialogues/)点「先看一个示例书库」 |
| 想开始读自己的记录，怕麻烦 | **第二步之 A（在线版）**——零安装 |
| 打算长期用、数据多、想最稳 | **第二步之 B（装到电脑上）**——多花五分钟 |
| 只有手机 | 在线版，见[手机上怎么用](#手机上怎么用) |

> **「我的记录会被上传吗？」——不会。** 不管在线版还是本地版，
> 文件都只在你自己的浏览器里解析，全程不离开你的设备。
> 在线版只是「网页本身」放在 GitHub 上，你的数据不会发给任何人。

## 第一步：把你的聊天记录导出来

阅读器认识下面这几种「官方导出」。你先去对应的平台把数据拿到手：

### ChatGPT

1. 打开 ChatGPT → 左下角头像 → **Settings（设置）**
2. **Data controls（数据控制）** → **Export data（导出数据）** → 确认
3. 等邮件（一般几分钟内），点邮件里的 **Download data export** 下载一个 `.zip`
4. **解压它**，得到一个文件夹——这个文件夹就是待会要选的东西

### Claude

1. 打开 claude.ai → 左下角头像 → **Settings（设置）**
2. **Privacy（隐私）** → **Export data（导出数据）**
3. 等邮件，下载 `.zip`，**解压**——里面的 `conversations.json` 就是待会要选的东西

### Mufy

Mufy 自带的导出一次只能点一条，角色多了没法用。用我们做的批量导出脚本：

### 👉 <https://github.com/willwefind/mufy-batch-export>

那个仓库自己就有一份和这份同样风格的零基础教程（手机也能全程走通）。
导出来的 `.zip` **不用解压**，待会直接选。

> 💡 **导出要趁早。** 平台的数据不是永远都在——迁移、下架、过期都发生过。
> 导出来放在自己硬盘上的那一份，才是不会变的那一份。

## 第二步之 A：用在线版（推荐新手）

1. 打开 👉 <https://willwefind.github.io/our-dialogues/>
2. 左侧找到 **来源** 那一行，点右边的 **＋** 号
3. 按你手上的东西选按钮：

| 你手上是什么 | 点哪个按钮 |
|---|---|
| ChatGPT 解压出来的**文件夹** | **添加来源文件夹**（或「选择来源文件夹」） |
| Claude 的 `conversations.json` | **选择 JSON / ZIP** |
| Mufy 的一堆 `.zip` | 电脑：装 zip 的**文件夹**；手机：**选择 JSON / ZIP** 多选 |

4. 选完稍等片刻，左侧出现你的对话目录——点任何一条开始读

就这么简单。书签、划线、进度都会自动记住，**下次用同一个浏览器打开同一个网址**，
书库还在，还停在你上次读到的那一行。

> ⚠️ 换浏览器、换设备、清除浏览器数据，书库就要重新导入
> （原始文件还在你硬盘上，重导一遍就好，书签划线在同一浏览器里会保留）。

## 第二步之 B：装到自己电脑上

比在线版多五分钟，换来的是：不依赖网络、文件夹授权可以被记住、重开更稳。

### 1. 下载这个仓库

回到[仓库首页](https://github.com/willwefind/our-dialogues)，
找到那个**绿色的 Code 按钮** → 点开选 **Download ZIP** → 下载后**解压**到
一个好找的地方（比如 D 盘），得到一个 `our-dialogues-main` 文件夹。

> 点开文件夹会看到一堆代码文件——**正常的**，不用管它们。

### 2. 装 Node.js（免费，装一次就完）

启动器需要它。去官网：

<https://nodejs.org/>

点绿色的 **LTS** 大按钮下载，安装时**一路下一步**就行，什么都不用改。

> **Node 是什么？** 一个让电脑能跑网页服务的小工具，很多正经软件都用它。
> 装了它只是多了个工具，不会改变你电脑上任何别的东西。

### 3. 双击启动

在解压出来的文件夹里找到 **`Start Reader.bat`**，**双击**。
会闪出一个黑色窗口（别关它），然后浏览器自动打开阅读器
（地址是 `http://127.0.0.1:4173/`——这是你自己电脑上的本地地址，不是外网）。

之后照 [第二步之 A](#第二步之-a用在线版推荐新手) 的第 2 步开始导入就行。

> - **Mac / Linux**：双击（或在终端运行）`start-reader.sh`
> - 想关掉就关黑色窗口；想再用就再双击。书库一直都在。
> - 🚨 **每次都用这个启动器打开**，别直接双击 `index.html`——原因见下一节。

## 🚨 最重要的一个坑：三个「书库」互不相通

> **浏览器的本地存储是按「网址」隔离的。** 也就是说：
>
> | 你从哪里打开 | 书库 |
> |---|---|
> | 在线版 `willwefind.github.io` | 书库 ① |
> | 启动器 `127.0.0.1:4173` | 书库 ② |
> | 直接双击 `index.html`（`file://`） | 书库 ③ |
>
> **这三个是三个独立的世界，互相看不见对方的书。**
>
> 「我昨天明明导过，今天全空了！」——十有八九是今天换了一种方式打开。
> 内容没有丢，回到昨天那种打开方式就在。
>
> **对策：选定一条路就一直走它。** 长期用推荐启动器
> （它把端口钉死在 4173，就是为了让书库永远是同一个）。

## 手机上怎么用

- 直接用**在线版**，界面会自动变成手机版：底部翻页条、抽屉侧栏、轻点正文呼出控件
- 导入时**用「选择 JSON / ZIP」并一次多选**（文件选择框里长按 / 勾选多个）
- 🚨 **别用「选择文件夹」**——手机浏览器的文件夹选择常常退化成一次只能选一个，
  几十个文件会点到崩溃
- ChatGPT 的导出文件夹在手机上不好处理，建议这一种在电脑上导入；
  Claude 的单个 JSON 和 Mufy 的 ZIP 手机上都没问题

## 进阶：连上语音

如果你保存了对话的语音档案（TTS 输出、录音），阅读器可以把每段音频放到
**说出它的那句话旁边**，点一下就能听。

来源 **＋** 菜单 → **语音档案（可选）** → 选择装着「映射 JSON + 音频文件」的文件夹。

映射文件怎么来：见[搬家指南的语音一节](bring-your-own-archive.zh-CN.md#进阶让你自己的语音也躺进正文旁边)——
让你家的 AI 照着现成的提示词生成一份就行。

> 语音永远只在本机播放，不会被复制进浏览器、更不会上传。
> 刷新页面后点「重新连接来源」再选一次文件夹即可。

## 常见问题

**Q：书库突然空了 / 内容消失了？**
先看 [🚨 三个书库互不相通](#-最重要的一个坑三个书库互不相通)——
99% 是换了打开方式。剩下 1% 是浏览器清了数据：重新导入原始文件即可。

**Q：选了文件夹却说「什么都没找到」？**
如果文件放在**云盘同步目录**（OneDrive / WPS 云盘等），本地可能只有「占位文件」，
浏览器读不到内容。**先把文件夹复制到本地硬盘**（比如 D 盘）再选。

**Q：导入要等多久？数据太大会不会崩？**
几百段对话通常几秒钟。文字占不了多少空间（浏览器给每个网站的存储通常有几百 MB 起），
附件和音频**不会**被存进浏览器，所以书库再大也轻。

**Q：怎么更新到新版本？**
在线版永远是最新的。本地版：重新 Download ZIP 解压覆盖一遍就行——
**书库在浏览器里，不在那个文件夹里**，覆盖不会丢任何东西
（前提：还是用启动器、还是那个 4173 端口）。

**Q：这个东西收费吗？要注册吗？**
不收费、不注册、没有账号系统。代码开源（AGPL-3.0），永远可以自己下载一份。

**Q：遇到问题去哪问？**
[提 issue](https://github.com/willwefind/our-dialogues/issues)。
描述问题时**永远不要贴真实对话内容**——用「结构一样、内容是编的」合成样例，
或者只描述现象和报错文字。
